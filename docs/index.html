kKEo's Claude Code plugins

The km-plugins marketplace holds two installer plugins. Each one sets up a mod from the incubator marketplace: a pane that sits beside the chat in Claude Code. Every plugin has a book of its own that covers both the installer and the mod.

Plugin and mod

session-cost-installer

Installs session-cost: a pane listing every model request of the session with its tokens and cost, with totals by model and by day.

Quick start

At the prompt of a Claude Code session. The sentences in the middle are requests to Claude; they start the installer skills.

/plugin marketplace add kKEo/claude-code-plugins
/plugin install session-cost-installer@km-plugins
/plugin install plan-progress-installer@km-plugins
/reload-plugins

install session-cost
install plan-progress

/reload-plugins
/session-cost
/plan-progress
